# T06: Command journal outbox and leases

Status: implemented, independently reviewed and verified. Updated 2026-11-18.

- Dependencies: T05.
- Requirements: FR07, FR13, FR15 in [PRD](../docs/PRD.md).
- Complexity: M (relative uncertainty, not a delivery promise).
- Agent recommendation: one executor using an available capable model, high effort;
  independent reviewer afterward. No parallel agent work by default.

## Objective

Make dispatch recoverable without long-running conversation jobs.

## Scope and relevant areas

Laravel workflow actions, SQLite migrations and connection settings, and a
scheduled outbox job. See [architecture](../docs/ARCHITECTURE.md).

## Acceptance criteria

- [x] Persist command intent and outbox with state before external dispatch.
- [x] Duplicate dispatch uses stable idempotency identity and does not duplicate mutation.
- [x] Use short jobs with explicit deadlines; no dependency on PCNTL for Windows correctness.
- [x] Record lease generations and block replacement until an old writer is fenced/stopped.
- [x] Missed publishing/acknowledgement enters reconciliation, not blind resend.

## Validation and handoff

Entering planning writes the state transition, audit event, command and
outbox entry in one transaction. Workflow ID, version and command kind identify
the operation. The outbox publishes to a SQLite runner inbox in a bounded sweep.
Expired unpublished, unclaimed and unacknowledged entries require reconciliation.
A single runner lease protects the dispatch slot across workflows. Expiry blocks
new claims and acknowledgements. Replacement requires trusted process-stop
evidence for the prior generation. T06 records that evidence at the Laravel
boundary. Native process verification and wire dispatch belong to later tasks.
While a generation can still send a claimed planning command, amendments wait
for acknowledgement or verified process shutdown. Start a companion
`php artisan schedule:work` process alongside `composer dev` to run the sweep
locally.

On Windows PHP 8.5.12, Pint and PHPStan passed. The full Laravel suite passed
with 62 tests and 249 assertions.
Tests exercise rollback, repeat publication, duplicate claims, lost
acknowledgement, lease expiry and replacement, and superseded commands.
Upgrade coverage verifies that existing Planning workflows receive a
reconciliation record. A backlog test verifies that 101 expired commands
cannot block a live publication.
Independent read-only Codex reviews identified deadline, publication, amendment,
upgrade and commit recovery gaps. Regression tests cover the fixes, including
a blocked commit during both migration and sweep and an interrupted backfill.
The final migration fix was verified by a same-connection retry test.
Artisan listed the sweep at ten-second intervals. Native macOS and live
wire dispatch remain outside this evidence.

## Excluded scope and budget

No unrelated features, dependency upgrades or scope expansion. Installation, native sandbox
setup and new dependencies need specific approval. Budget: one focused task/role session;
record estimated token/time range and confidence before dispatch. Numeric estimates remain
unknown until T01-T03 establish measurements. Split L tasks at the named boundary before
implementation approval if they cannot be reviewed independently.
