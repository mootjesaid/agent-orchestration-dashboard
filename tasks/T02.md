# T02: Native isolation and process proof

Status: Windows isolation and lifecycle evidence recorded; safety gate remains open.
Updated 2026-11-18. Evidence: [capability results](../docs/CAPABILITY-VALIDATION.md).

termination of an owned synthetic process tree. App Server interrupted an active
model turn. A read-only subprocess read its sentinel and was denied a write.

## Objective

Prove enforced role restrictions and native process lifecycle before enabling writes.

## Scope and relevant areas

## Acceptance criteria

- [ ] Read-only roles cannot create/edit/delete project files through shell, tools, MCP or child processes.
- [ ] Executor cannot alter protected Git metadata, other repositories, orchestrator state or secrets; demonstrate an enforceable broker boundary.
- [ ] Test path spaces/Unicode, symlinks/junctions, drive boundaries, network denial and inherited configs/hooks.
- [ ] Prove bidirectional PHP stdio, bounded output, interrupt, process-tree stop, terminal exit and sleep/restart handling.
- [ ] Record exact native OS builds; any failed core guarantee blocks execution and requires revised design, never silent weakening.

The remaining matrix includes MCP and inherited configuration isolation,
shared Git metadata and broker enforcement, path redirects and drive boundaries,
network denial, interruption during a tool, native Codex process-tree cleanup,
terminal exit, sleep/wake, and native macOS. The read-only sandbox checks are
limited to the exercised disposable paths.

The standalone Windows clone probe verified separate Git metadata and denied
writes to both Git configs. A disposable file outside the clone remained
writable under the tested policy. The executor workspace boundary failed.

Windows Sandbox was selected for a disposable host write-boundary probe.
DISM enabled the optional feature with `/NoRestart` and returned 3010.
The executable was still unavailable before restart. After restart, run
`storage/app/private/t02-windows-sandbox.ps1` once to verify a writable
working-files mapping and a read-only protected mapping. Executor writes
remain gated.
