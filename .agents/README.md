# Durable project context

Read [project-memory.md](project-memory.md) at the start of every session, then the
root [AGENTS.md](../AGENTS.md). These two files are intentionally versioned.

The product specifications live in `docs/`; implementation units live in `tasks/`.
This folder holds a compact handoff, not a second specification or Codex runtime
configuration. Existing `skills/` is generated development tooling and remains
ignored by Git. No runtime agents have been installed or configured by this plan.

After an approved change, update the current phase, completed task IDs, decisions,
actual verification and next action in the memory. Preserve open questions until
the user resolves them. Never infer implementation approval from a previous plan.
